デスクトップデータベースを、
Access 流に。

BaseCraft は、Microsoft Access の発想を受け継ぐオープンソースのデスクトップデータベースアプリケーションです。テーブル、クエリ、フォーム、レポート、マクロ、コードを、モダンなインターフェイスで。Windows、macOS、Linux で動作します。

プレビュー版をダウンロード GitHub で見る UI モックアップを見る

BaseCraft の特長

使い慣れている

すべてのオブジェクトにデザインビューと実行ビュー、QBE クエリグリッド、データシート、プロパティシートがあります。Access を知っていれば、BaseCraft もすぐに使えます。

オープンな単一ファイル

データベース全体が 1 つの .basecraft ファイルに収まります。これは通常の SQLite データベースで、どの SQLite ツールでも読み取れます。

クロスプラットフォーム

Windows、macOS、Linux に対応した 1 つのアプリケーションです。個人利用ならサーバーも追加のインストールも不要です。

標準で安全

クラッシュしてもデータは失われません。マシン間では書き込みロックが働き、メールで受け取ったファイルがコンピューターに害を及ぼすこともありません。

ロードマップ

  1. A Excel の置き換え: テーブル、リレーションと式、クエリ、フォーム、レポート、PDF エクスポート ✓
  2. B 自動化と配布: イベント、マクロ、BaseCraft Runtime
  3. C 共同作業: PostgreSQL、SQL Server、Access へのリンクテーブル
  4. D VBA の代わりに Python コード
  5. E 既存の Access データベースのインポート
