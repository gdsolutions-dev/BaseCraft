Desktop databases,
the Access way.

BaseCraft is an open-source desktop database application in the spirit of Microsoft Access. Tables, queries, forms, reports, macros and code, with a modern interface, on Windows, macOS and Linux.

Download preview (Windows, Linux) View on GitHub See the UI mockups

Why BaseCraft

Familiar

Design view and run view for every object, a QBE query grid, datasheets and property sheets. If you know Access, you know BaseCraft.

One open file

A whole database lives in one .basecraft file, which is a plain SQLite database any SQLite tool can read.

Cross-platform

One application for Windows, macOS and Linux. No server and nothing else to install for solo use.

Safe by default

No data lost after a crash, write locking across machines, and files received by email cannot harm your computer.

Roadmap

  1. A Replace Excel: tables ✓, relations and expressions (in progress), queries, forms, reports and PDF export
  2. B Automate and distribute: events, macros, BaseCraft Runtime
  3. C Work together: PostgreSQL, SQL Server and Access linked tables
  4. D Python code in place of VBA
  5. E Import existing Access databases
