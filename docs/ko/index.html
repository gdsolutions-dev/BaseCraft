데스크톱 데이터베이스,
Access의 방식으로.

BaseCraft는 Microsoft Access의 정신을 잇는 오픈 소스 데스크톱 데이터베이스 애플리케이션입니다. 테이블, 쿼리, 폼, 보고서, 매크로, 코드를 현대적인 인터페이스로 Windows, macOS, Linux에서 사용할 수 있습니다.

BaseCraft를 쓰는 이유

익숙함

모든 개체에 디자인 보기와 실행 보기가 있고, QBE 쿼리 그리드, 데이터시트, 속성 시트를 제공합니다. Access를 안다면 BaseCraft도 바로 쓸 수 있습니다.

하나의 열린 파일

데이터베이스 전체가 하나의 .basecraft 파일에 들어 있으며, 이 파일은 어떤 SQLite 도구로도 읽을 수 있는 일반 SQLite 데이터베이스입니다.

크로스 플랫폼

Windows, macOS, Linux에서 하나의 애플리케이션을 씁니다. 혼자 쓸 때는 서버도, 다른 설치도 필요 없습니다.

기본적으로 안전

충돌이 나도 데이터가 손실되지 않고, 컴퓨터 간 쓰기 잠금을 지원하며, 이메일로 받은 파일이 컴퓨터를 해칠 수 없습니다.

로드맵

  1. A Excel 대체: 테이블, 관계와 식, 쿼리, 폼, 보고서, PDF 내보내기 ✓
  2. B 자동화와 배포: 이벤트, 매크로, BaseCraft Runtime
  3. C 함께 작업: PostgreSQL, SQL Server, Access 연결 테이블
  4. D VBA 대신 Python 코드
  5. E 기존 Access 데이터베이스 가져오기
