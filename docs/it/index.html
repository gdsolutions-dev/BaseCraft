Database desktop,
alla maniera di Access.

BaseCraft è un'applicazione database desktop open source nello spirito di Microsoft Access. Tabelle, query, maschere, report, macro e codice, con un'interfaccia moderna, su Windows, macOS e Linux.

Scarica l'anteprima Vedi su GitHub Vedi i mockup dell'interfaccia

Perché BaseCraft

Familiare

Visualizzazione Struttura e visualizzazione di esecuzione per ogni oggetto, una griglia di query QBE, fogli dati e finestre delle proprietà. Se conosci Access, conosci BaseCraft.

Un unico file aperto

Un intero database vive in un solo file .basecraft, un semplice database SQLite che qualsiasi strumento SQLite può leggere.

Multipiattaforma

Un'unica applicazione per Windows, macOS e Linux. Nessun server e nient'altro da installare per l'uso singolo.

Sicuro per impostazione predefinita

Nessun dato perso dopo un arresto anomalo, blocco in scrittura tra le macchine e i file ricevuti via e-mail non possono danneggiare il tuo computer.

Roadmap

  1. A Sostituire Excel: tabelle, relazioni ed espressioni, query, maschere, report ed esportazione PDF ✓
  2. B Automatizzare e distribuire: eventi, macro, BaseCraft Runtime
  3. C Lavorare insieme: tabelle collegate PostgreSQL, SQL Server e Access
  4. D Codice Python al posto di VBA
  5. E Importare database Access esistenti
