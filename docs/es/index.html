Bases de datos de escritorio,
al estilo Access.

BaseCraft es una aplicación de bases de datos de escritorio de código abierto en el espíritu de Microsoft Access. Tablas, consultas, formularios, informes, macros y código, con una interfaz moderna, en Windows, macOS y Linux.

Por qué BaseCraft

Familiar

Vista Diseño y vista de ejecución para cada objeto, una cuadrícula de consulta QBE, hojas de datos y hojas de propiedades. Si conoces Access, conoces BaseCraft.

Un único archivo abierto

Toda una base de datos vive en un archivo .basecraft, que es una base de datos SQLite normal que cualquier herramienta SQLite puede leer.

Multiplataforma

Una sola aplicación para Windows, macOS y Linux. Sin servidor y sin nada más que instalar para uso individual.

Seguro por defecto

Sin pérdida de datos tras un fallo, bloqueo de escritura entre equipos, y los archivos recibidos por correo electrónico no pueden dañar tu ordenador.
